# ADHD & Executive Function Tool

A private, offline, single-file web app to help adults with ADHD plan, focus,
and follow through. Everything is stored locally in the browser — nothing is
sent to any server.

Modules: Tasks (master list + breakdown), Plan (day blocks), Focus (timed
sessions), If-Then plans, Rewards, and an Accountability Buddy contract.

Made by Dr Aana Shah (https://draanashah.com). Built with the help of AI tools.
Grounded in established cognitive-behavioural principles for adult ADHD,
drawing on the work of Russell A. Barkley and on *Mastering Your Adult ADHD*
(Safren, Sprich, Perlman & Otto).
